# 0063. The train speaks in steam-era railway terms

- Status: accepted
- Date: 2026-11-20
- Decided by: the owner

## Context

The owner's taste.

## Options weighed

- Period engravings (weighed and dropped for the drawn set)
- A drawn picture per state

## Decision

The workflows, jobs, run summary and comments carry punning names and emoji, a drawn picture per state, and one line that shows the train with a carriage per pull request (`🚂-🚃#37-🚃#39`). Every message still says in a plain sentence what happened and what to do. No pull request numbers in the pictures: that needs a picture per run.

## Consequences

The drawn set covers every state and reads on a light and a dark page.
