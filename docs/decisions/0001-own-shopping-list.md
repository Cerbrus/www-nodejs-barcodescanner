# 0001. Own shopping list, no Bring

- Status: accepted
- Date: 2026-11-12
- Decided by: the owner (feature review)

## Context

The list could live in Bring or in this app. Bring has no quantity field, its API is unofficial, and the web page exists anyway.

## Options weighed

- Bring as the list target
- An own shopping list in this app

## Decision

Own shopping list in this app. No Bring.

## Consequences

Bring's web app remains a reference for the list page, see [0058](0058-bring-as-reference.md).
