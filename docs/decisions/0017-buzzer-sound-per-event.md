# 0017. The sound per scan result is a setting, from a fixed library

- Status: superseded by [0020](0020-sounds-from-building-blocks.md)
- Date: 2026-11-12
- Decided by: the owner

## Context

The user wanted to try sounds from the web page and pick per event.

## Options weighed

- Hard-coded in the hardware agent
- A setting in the app, from a fixed library
- Free editing of own patterns

## Decision

The sound per scan result is a setting in the app, chosen from a fixed library, not hard-coded in the hardware agent. Free editing of own patterns was left out; new sounds are added to the library on request.

## Consequences

Replaced by [0020](0020-sounds-from-building-blocks.md).
