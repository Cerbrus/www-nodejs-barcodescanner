# 0032. Images and build follow the newest Node release

- Status: accepted
- Date: 2026-11-13
- Decided by: the owner

## Context

The owner wants the newest runtime.

## Options weighed

Not recorded.

## Decision

The images and the build follow the newest Node release, 25 at the time, also when it is not a long-term one. The build's tests run on the same version as the image.

## Consequences

Local development works on 24 or newer.
