# Documentation

Scan the barcode of an empty package before tossing it, and the product lands on the household shopping list.

| Document | Content |
|---|---|
| [use-cases.md](use-cases.md) | What the product does, from the user's point of view |
| [decisions.md](decisions.md) | Feature and technology choices, with the reasoning |
| [architecture.md](architecture.md) | Target architecture, data model, API, scan rules |
| [deployment.md](deployment.md) | Raspberry Pi setup, auto-update, reverse proxy |
| [plan.md](plan.md) | Milestones from the current prototype to the usable product |
| [../data/seed-items.json](../data/seed-items.json) | Seed data: sections and items with icon and emoji, current list state |

The repository currently holds the prototype. `architecture.md` and `deployment.md` describe the target; `plan.md` says how to get there and what the prototype looks like today.
